LingoMiner AI

Convierte cualquier texto en tarjetas Anki con cloze real.

LingoMiner AI es una extensión de navegador que transforma las frases que seleccionas mientras navegas en tarjetas Anki listas para estudiar. A diferencia de otras herramientas de sentence mining, LingoMiner no se limita a extraer texto: analiza la frase con inteligencia artificial y genera una tarjeta de cloze real con traducción contextual, nota gramatical, fonética del lema y clasificación taxonómica.

Qué hace especial a LingoMiner

Cloze real de Anki

Usa el tipo de nota nativo con {{c1::...}}. Scheduler específico, estadísticas nativas y compatibilidad total con Anki, AnkiDroid y AnkiMobile.

Arquitectura L1/L2

Declara tu idioma nativo (L1) y LingoMiner detecta el idioma del texto (L2). Las traducciones y las notas gramaticales se generan siempre en tu idioma.

Análisis lingüístico

Clasifica el input como oración, sintagma, palabra o unidad multipalabra. Cuando la selección no tiene contexto suficiente, genera una oración natural que la contenga.

Sincronización directa con Anki

Vía AnkiConnect en el puerto 8765. Sin archivos intermedios, sin pasos manuales, sin fricción.

Taxonomía cuadridimensional

Cada tarjeta se clasifica con 4 etiquetas: dominio, función pragmática, nivel (MCER, JLPT, HSK o TOPIK) y registro u origen.

Privacidad por diseño

Modelo BYOK: tú traes tu propia clave de API de Google Gemini. Sin servidores intermedios. Los datos se quedan en tu navegador y en tu Anki.

Idiomas soportados

LingoMiner soporta actualmente 11 idiomas como idioma objetivo:

Lenguas occidentales con marco MCER: inglés, gallego, alemán, francés, italiano, portugués, catalán y euskera.

Lenguas con marco específico: japonés (JLPT), chino mandarín (HSK) y coreano (TOPIK).

Requisitos técnicos

  • Navegador: Chrome o Edge (versión 103 o superior)
  • Anki: versión 2.1.50 o superior
  • AnkiConnect: add-on de Anki (código 2055492159)
  • Cuenta de Google: para obtener la API Key de Gemini
  • Sistema operativo: Windows, macOS o Linux

Sobre el audio

LingoMiner genera tarjetas con el texto listo para locución. El audio puede generarse de tres formas: con el TTS integrado del navegador, con la voz de Google Cloud TTS a través de AwesomeTTS, o con grabaciones propias. En idiomas minoritarios como el gallego, el catalán o el euskera, la calidad del TTS del navegador depende de las voces instaladas en tu sistema. Recomendamos configurar AwesomeTTS con Google Cloud para obtener resultados profesionales.
