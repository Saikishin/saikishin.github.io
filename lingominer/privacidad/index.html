Política de privacidad de LingoMiner AI

Última actualización: 2 de octubre de 2026 · Versión 3.0.2

1. Introducción

LingoMiner AI es una extensión de navegador que convierte las selecciones de texto en tarjetas de Anki con cloze real, utilizando la API de Google Gemini para el análisis lingüístico. Esta política describe de forma transparente qué datos toca la extensión, dónde se almacenan y con quién se comparten.

2. Qué datos maneja

LingoMiner AI solo trata los datos estrictamente necesarios para cumplir su única función: crear tarjetas de Anki a partir de las frases que el usuario selecciona explícitamente.

  • Texto seleccionado por el usuario: la frase o palabra que el usuario decide minar.
  • Clave de API de Gemini: la clave que el propio usuario introduce en la configuración (modelo BYOK).
  • Tarjetas minadas: el conjunto de tarjetas generadas y almacenadas localmente.
  • Preferencias de configuración: idioma nativo (L1), idioma de la interfaz y mazo de destino en Anki.

La extensión no recopila datos de análisis, telemetría, historial de navegación, información personal identificable ni ningún dato no relacionado con su función.

3. Dónde se almacenan

Todos los datos se guardan exclusivamente en chrome.storage.local, en el equipo del usuario. No se transmiten a servidores del desarrollador ni a ningún otro tercero, excepto los envíos directos que se describen a continuación.

  • Clave de API: almacenada localmente. Se usa únicamente para autenticar las peticiones a Google Gemini.
  • Tarjetas minadas y preferencias: almacenadas localmente. Persisten hasta que el usuario las elimine manualmente o desinstale la extensión.

4. Qué se envía y a quién

LingoMiner AI solo contacta con servicios externos cuando el usuario lo solicita explícitamente mediante una acción (botón flotante, menú contextual o atajo de teclado).

  • Google Gemini API: cuando el usuario mina una frase, el texto seleccionado se envía directamente desde el navegador del usuario a la API de Google Gemini para su análisis. Esta transmisión se realiza directamente, sin servidores intermediarios del desarrollador. El tratamiento posterior de esos datos se rige por la política de privacidad de Google.
  • AnkiConnect: cuando el usuario sincroniza, la extensión se comunica con AnkiConnect en http://127.0.0.1:8765. Esta comunicación es estrictamente local, en el propio equipo del usuario.

La clave de API del usuario nunca se transmite a servidores del desarrollador. Viaja directamente a Google como parte de la autenticación de la petición.

5. Permisos y finalidad

  • storage: almacenar localmente la clave de API, las tarjetas minadas y las preferencias.
  • contextMenus: añadir la opción «Minar con LingoMiner AI» al menú contextual.
  • host_permissions generativelanguage.googleapis.com: realizar las peticiones a la API de Google Gemini.
  • host_permissions 127.0.0.1 y localhost: comunicarse con AnkiConnect en el puerto 8765.

La extensión no solicita permisos de historial, pestañas, marcadores ni ningún otro que no sea imprescindible para su funcionamiento.

6. Retención y eliminación

  • Datos locales: permanecen en el equipo del usuario hasta que este los elimina desde el panel de la extensión o desinstala la extensión.
  • Datos enviados a Google: el tratamiento y la retención por parte de Google se rigen por la política de privacidad de Google. El usuario puede consultar los detalles en la política de privacidad de Google.
  • Eliminación de datos: el usuario puede vaciar el mazo local, borrar tarjetas individuales o desinstalar la extensión para eliminar todos los datos locales.

7. Seguridad

  • Comunicaciones cifradas: todas las peticiones a la API de Google Gemini se realizan sobre HTTPS.
  • Almacenamiento local: los datos se guardan en chrome.storage.local, que está aislado por el navegador.
  • Sin servidores propios: al no existir un backend del desarrollador, no hay riesgo de filtración desde servidores externos.

8. Derechos del usuario

El usuario tiene control total sobre sus datos:

  • Acceso: puede ver todas las tarjetas minadas desde el panel de la extensión.
  • Eliminación: puede borrar tarjetas individuales o vaciar el mazo completo.
  • Portabilidad: puede exportar las tarjetas a un archivo TSV.
  • Retirada del consentimiento: puede desinstalar la extensión, lo que elimina todos los datos locales.

9. Cambios en la política

Si se realizan cambios materiales en esta política, se actualizará la fecha de «última actualización» y se notificará a los usuarios a través de la ficha de la Chrome Web Store.

10. Contacto

Para cualquier consulta sobre esta política de privacidad, el usuario puede escribir a hola@saikishin.com.
